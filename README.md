# Testes com YOLOv26

Projeto desenvolvido para comparação entre os modelos YOLOv26:

- Nano (n)
- Small (s)
- Medium (m)
- Large (l)
- Extra Large (x)

## Objetivo

Analisar a relação entre precisão de detecção e tempo de inferência em imagens complexas.

## Ferramentas utilizadas

- Python
- Google Colab
- Ultralytics
- GIT HUB

## Estrutura do projeto

- `codigo/` → scripts utilizados
- `imagens/` → imagem original
- `resultados/` → resultados obtidos pelos modelos

## Resultados

Os testes demonstraram que modelos maiores apresentam melhor precisão na detecção de objetos, porém com maior tempo de inferência.
